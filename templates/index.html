Sobre a CantinaTech

A CantinaTech foi desenvolvida para facilitar a realização de pedidos antecipados na cantina escolar. O sistema permite que os alunos escolham seus produtos com antecedência, reduzindo filas e melhorando a organização do atendimento.

O projeto foi desenvolvido utilizando Python, Flask, HTML, CSS, Bootstrap e SQLAlchemy com SQLite para armazenamento das informações, oferecendo uma interface simples, intuitiva e acessível.
